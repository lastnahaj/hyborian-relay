# Getting Started

This guide is for a Conan Exiles Enhanced server with **5x rates** and **full PvP**. Begin with the
server overview, then compare your client against the canonical Workshop list.

## First steps

1. Read the [server overview](./server-overview.md) for the facts currently confirmed.
2. Check all entries in the [required mod list](./required-mods.md) by Workshop name and ID.
3. Use the wiki's system pages for controls and player-facing features.

Connection details, a server name, and any unconfirmed rules are intentionally absent until the
server owner supplies them.
