# Simple Modlist

**Source mod:** Simple Modlist v5.0.6 (by Xevyr) (`3719546290`)

Simple Modlist adds the active mod list to the **ESC** screen. It displays mod names and versions,
supports scrolling through long lists, and allows the displayed list to be copied as text.

Use the [required mod directory](../getting-started/required-mods.md) when comparing the displayed
list against this server's documented stack.
