# Stacksize Plus

**Source mod:** Stacksize Plus v2.0.3 (Enhanced) (`3720915336`)

Stacksize Plus increases stack sizes for supported base-game, DLC, and modded items while leaving
normally non-stackable items non-stackable. The mod documents a configurable multiplier range from 1
through 100 and notes that changed settings take effect when a stack is moved between inventories or
containers.

That range describes what the mod supports, not this server's setting. The effective server stack
multiplier has not been supplied and is not inferred from the server's general 5x identity. Item or
category values will be added only after live confirmation.
