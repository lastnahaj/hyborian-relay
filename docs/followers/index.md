# Followers

Three dedicated Enhanced mods improve follower handling without changing this guide into a server
configuration manual.

- [Better Thralls](./better-thralls.md) — group commands and optional follower-management systems.
- [Extended Thrall Stats](./extended-thrall-stats.md) — more information in follower stat panels.
- [Follower Collision](./follower-collision.md) — movement through a player's own followers.

Wings Of Valhalla and Armory and Arsenal also document follower-related progression and content;
those features remain on their respective system pages until live availability is verified.
