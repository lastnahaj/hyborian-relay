# Follower Collision

**Source mod:** [Enhanced] Player Ignores Follower Collision (`3720753923`)

The mod allows players to move through their own followers instead of being physically blocked by
them. The follower still fights, takes damage, and blocks other actors normally; the change is
limited to the owning player's collision with that follower.

## Player settings

Open the settings from the in-game console with `dc PIFCSettings`. The author documents these
per-character choices:

- Enable or disable the behavior.
- Apply it only to the active follower or to all owned followers.
- Include hostile NPCs, which is off by default in the mod.

Clan-owned followers count as owned for the documented collision behavior. A server-wide choice can
override an individual setting, so the options visible in the menu may not all control the final
behavior here.

If a global server choice changes the effective behavior, this page will describe the resulting
player experience after it is observed.
