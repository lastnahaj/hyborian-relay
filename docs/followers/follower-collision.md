# Follower Collision

**Source mod:** [Enhanced] Player Ignores Follower Collision (`3720753923`)

The mod allows players to move through their own followers instead of being physically blocked by
them. The Enhanced version also exposes player-side settings for how this behavior applies.

If a global server choice changes the effective behavior, this page will describe the resulting
player experience after it is observed.
