# Progression

Three parts of the Enhanced stack can shape character growth in different ways:

| System                                               | Documented scope                                          | What is published here              |
| ---------------------------------------------------- | --------------------------------------------------------- | ----------------------------------- |
| [Wings Of Valhalla](./wings-of-valhalla.md)          | Character progression, professions, rewards, and bounties | Source-documented system map only   |
| [EAA - Enhanced Perks & Level](./eaa-perks-level.md) | Levels, attributes, and perk milestones                   | No final server cap or schedule yet |
| [Armory and Arsenal](./armory-and-arsenal.md)        | Class experience and ascension                            | Source-documented system map only   |

## Current player guidance

Do not use a single mod's default table as the server's effective progression table. Wings Of
Valhalla and EAA both affect progression, and their combined live behavior has not been supplied.

The exact level cap, experience curve, attribute-point schedule, perk milestones, class-XP values,
and ascension values will be added only after the loaded server is observed and recorded.

## What is safe to rely on

- The server is configured around 5x rates, but no category-by-category rate table has been
  supplied.
- All three systems above are present in the required Enhanced mod stack.
- Any exact progression values that later appear here must be live-server values, not assumed mod
  defaults.
