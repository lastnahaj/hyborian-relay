# EAA — Enhanced Perks & Level

**Source mod:** [Enhanced] EAA - Enhanced Perks & Level (`3720326124`)

EAA changes the base level, attribute, and perk model. Wings Of Valhalla also provides character
level functionality, so values documented for EAA alone cannot be treated as the final server
behavior.

## What is intentionally not published yet

- Final character level cap
- Effective experience curve
- Total attribute-point schedule
- Attribute caps and exact perk milestones
- Respec behavior or costs

Those values need a live-server record with both progression systems loaded in the actual server
order. Until then, this page serves as a verification checkpoint rather than a progression table.
