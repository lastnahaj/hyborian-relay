# Armory and Arsenal

**Source mod:** [Enhanced] Armory and Arsenal v1.2.9 (`3718199031`)

Armory and Arsenal is documented as a connected progression, gear, and endgame system rather than a
single equipment pack.

## Documented system map

| Area                 | Public source describes                                             |
| -------------------- | ------------------------------------------------------------------- |
| Character paths      | Three skill trees, five classes, and separate class experience      |
| Equipment growth     | Perk runes, collectable gems, accessories, and equipment enchanting |
| Gear                 | Hundreds of weapons and armor pieces, plus enhanced tools           |
| Encounters           | Endgame bosses, named followers, and merchants                      |
| Advanced progression | Weapon-scaling conversion and ascension                             |

## What will be added after live verification

Focused guides can cover class selection, class experience, skill trees, gear acquisition, gems,
enchanting, merchants, bosses, and ascension. Exact values, acquisition paths, and availability are
not published until they are confirmed on this server.
