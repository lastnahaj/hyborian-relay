# Building Placement

**Source mod:** Less Building Placement Restrictions (Enhanced) - v1.0.3 (`3755091710`)

The mod documents configurable placement flexibility including blocker behavior, overlap exceptions,
follower-placement improvements, directional placement helpers, and client preview options. Its
current Enhanced page also documents a restored **Tab** shortcut for building health, decay, and
stability information, plus personal choices between a ghost preview and a solid-object preview.

Most important behavior is server-configurable. A final player guide needs observation of what can
actually be placed here and which restrictions remain; the mod's full option set is not presented as
the server rule set.
