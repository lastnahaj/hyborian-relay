# Building

The Enhanced stack combines construction quality of life with additional placeables and building
content.

- [Unlock Plus](./unlock-plus.md) — storage, material-pulling, deposit, restock, and construction
  movement tools.
- [Building Placement](./lbpr.md) — placement flexibility whose effective behavior depends on the
  server setup.
- [Highmane crafting, building, and decor](../combat/highmanes/crafting-building.md) — catalog
  structure for verified player-obtainable benches, sets, and decorations.
- [ExilesExtreme](../combat/exiles-extreme.md) — first-party references for structures and
  placeables.
