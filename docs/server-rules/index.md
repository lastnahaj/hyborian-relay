# Server Rules

The only confirmed competitive setting currently available to this guide is **full PvP**. A full
ruleset has not been supplied.

Raid windows, building limits, clan limits, conduct rules, wipe policy, prohibited tactics, and
enforcement details are intentionally absent. Do not treat their absence as permission or as a
statement of server policy.
