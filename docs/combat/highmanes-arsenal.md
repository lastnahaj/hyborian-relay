# Highmane's Arsenal

**Source mod:** Highmane's Arsenal: Enhanced (`3721926604`)

The Workshop documentation presents Highmane's Arsenal as a collection of more than 2,000 items,
including hundreds of weapons, custom movesets and effects, armor and clothing, accessories,
consumables, decorations, building sets, crafting benches, crafting expansions, pets, mounts, and
character customization.

## Publication standard

An item is added only after its ordinary-player acquisition and behavior on this server are
verified. Each entry records its source mod, category, acquisition route, crafting station,
requirements, player effect, PvP notes, server restrictions, sources, verification date, and image
provenance when an approved image exists.

No individual item entries have met that server-verification threshold yet. The structured catalog
is ready to receive them without publishing the full Workshop catalog as if every item were
available here.
